## 🚀 Mis proyectos destacados

### 🎬 Gestor de Películas
Aplicación de escritorio desarrollada con Java y JavaFX para gestionar contenido audiovisual.

**Tecnologías:** Java, JavaFX, MySQL y DAO.

🔗 [Ver proyecto](https://github.com/myketorres563/GestorDePeliculas)

### 📅 Gestor de Reservas
Aplicación web para gestionar reservas, con autenticación y comunicación entre frontend y backend mediante API REST.

**Tecnologías:** React, TypeScript, Express y Docker.

🔗 [Ver proyecto](https://github.com/myketorres563/GestorReservas)

### 💼 ClientFlow — Gestor de Clientes
Aplicación web para administrar clientes mediante operaciones CRUD, rutas protegidas y una API REST de demostración.

**Tecnologías:** React, TypeScript, Node.js y Express.

🔗 [Ver proyecto](https://github.com/myketorres563/Re-DesarrolloCliente)

### ✅ React Tareas API
Proyecto de aprendizaje centrado en el consumo de APIs REST y gestión de tareas.

**Tecnologías:** React, TypeScript, Axios y Vite.

🔗 [Ver proyecto](https://github.com/myketorres563/react-tareas-api)
